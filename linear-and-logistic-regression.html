Linear & Logistic Regression

When you need to predict a number from data — like tomorrow's temperature or a house price — you are solving a regression problem.

5 min read Intermediate

What is linear & logistic regression and why does it matter?

When you need to predict a number from data — like tomorrow's temperature or a house price — you are solving a regression problem. When you need to decide between two categories — spam or not spam, churn or stay — you are solving a binary classification problem. Linear regression and logistic regression are the simplest, most interpretable models for these two tasks. They are often the first model a practitioner tries, and they serve as baselines against which more complex models are measured. Linear regression fits a straight line (or hyperplane) to minimize the sum of squared errors between predictions and actual values. Logistic regression applies a sigmoid function to a linear combination of inputs, producing a probability between 0 and 1, then classifies based on a threshold. Both are fast to train, easy to explain, and require minimal tuning. But they also have strong assumptions: linear relationships, independence of errors, and (for logistic regression) no severe multicollinearity. When those assumptions hold, these models are hard to beat. When they don't, performance degrades quickly.

How it works

Linear & Logistic Regression

Linear regression models the target as a weighted sum of the input features. For a dataset with n features, the prediction is: y_pred = w0 + w1*x1 + w2*x2 + ... + wn*xn. The weights w are learned by minimizing the residual sum of squares between predictions and actual values. This is typically done using ordinary least squares (OLS), which has a closed-form solution.

Logistic regression, in contrast, models the log-odds of the positive class as a linear function: log(p/(1-p)) = w0 + w1*x1 + ... + wn*xn. Solving for p gives the sigmoid function: p = 1 / (1 + exp(-z)), where z is the linear combination. The weights are estimated using maximum likelihood estimation (MLE), which finds the weights that maximize the probability of observing the training data. There is no closed-form solution for logistic regression; weights are learned iteratively using algorithms like Newton-CG or gradient descent.

Both models are sensitive to feature scaling. For linear regression, unscaled features can cause gradient descent (if used) to converge slowly. For logistic regression, unscaled features can cause the solver to fail or produce unstable coefficients.

Common failure modes:
  • For linear regression: when the relationship between inputs and output is not linear — the model will underfit.
  • For logistic regression: when the data is not linearly separable; the model may still work but will produce probabilities near 0.5 for ambiguous regions.

Neither model handles non-linear relationships well without feature engineering or kernel tricks. Both models are sensitive to feature scaling — always standardize or normalize features before training. Regularization (L1 or L2) can help prevent overfitting, especially when the number of features is large relative to samples.

In practice

PYTHON
import numpy as np
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, accuracy_score

# Generate synthetic data
np.random.seed(42)
X = np.random.randn(100, 2)
y_reg = 3 + 2*X[:, 0] - 1.5*X[:, 1] + 0.5*np.random.randn(100)
y_clf = (1 / (1 + np.exp(-(1 + 2*X[:, 0] - 1.5*X[:, 1]))) > 0.5).astype(int)

# Split data
X_train, X_test, y_reg_train, y_reg_test = train_test_split(X, y_reg, test_size=0.2, random_state=42)
_, _, y_clf_train, y_clf_test = train_test_split(X, y_clf, test_size=0.2, random_state=42)

# Scale features
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

# Linear regression
lin_reg = LinearRegression()
lin_reg.fit(X_train_scaled, y_reg_train)
y_pred_reg = lin_reg.predict(X_test_scaled)
print(f"Linear Regression MSE: {mean_squared_error(y_reg_test, y_pred_reg):.3f}")
print(f"Coefficients: {lin_reg.coef_}")

# Logistic regression
log_reg = LogisticRegression(solver='newton-cg')
log_reg.fit(X_train_scaled, y_clf_train)
y_pred_clf = log_reg.predict(X_test_scaled)
print(f"Logistic Regression Accuracy: {accuracy_score(y_clf_test, y_pred_clf):.3f}")
print(f"Coefficients: {log_reg.coef_}")

Key takeaways

What you now know
  • Linear regression predicts continuous values using a weighted sum of inputs, minimized via ordinary least squares.
  • Logistic regression predicts binary outcomes by applying a sigmoid to a linear combination, estimated via maximum likelihood.
  • Both models assume a linear relationship between inputs and the log-odds (logistic) or the output (linear).
  • Feature scaling is critical for both models to ensure stable and fast convergence.
  • Neither model handles non-linear patterns without feature engineering or regularization to combat overfitting.
